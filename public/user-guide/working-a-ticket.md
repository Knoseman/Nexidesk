# Working on a Ticket

When you open a ticket, the header at the top gives you the controls you will use most often. Let us walk through them.

---

## The Header Controls

### Status

Click the coloured status badge to change it. The colour updates straight away so you know the change has taken effect.

| Status | Meaning |
|--------|---------|
| **New** | Just arrived, not yet attended to. Setting a ticket back to New also marks it as **unread** for all agents. |
| **Open** | Being worked on. Assigned automatically when an agent is added. |
| **Pending** | Waiting on the customer or a third party. |
| **Resolved** | Work is done, but the ticket is kept visible for a short time before closing. |
| **Closed** | Archived. Use the **Reopen** button to bring it back to Open. |

### Priority

Click the priority label to change it. The icon tells you the level at a glance:

| Icon | Meaning |
|------|---------|
| Clock | Low |
| Circle | Normal |
| Triangle | High |
| Lightning bolt | Urgent |

### Assignee

Click "Unassigned" (or the current agent's name) to open the list of active agents. Your own name is labelled **(Me)** in the list so you can quickly self-assign.

Choosing someone automatically moves a **New** ticket to **Open**.

To unassign a ticket, open the dropdown and select "Unassigned".

### Close / Reopen

The button in the top-right is a shortcut. It toggles the ticket between **Closed** and **Open**. If you want **Resolved** as a separate step, use the status dropdown instead.

---

## The Conversation Thread

The thread shows every event in the ticket in order:

- **Inbound messages** — emails from the customer or anyone outside your team.
- **Outbound messages** — replies you have sent. These show a delivery status while the email is being sent.
- **Internal notes** — only visible to agents. These never go to the customer.

### Delivery status

Outbound messages go through these stages: `pending` → `sending` → `sent` (or `failed`).

If a message stays on `sending` for more than a couple of minutes, tell your administrator. Do not resend it — they can check the queue without duplicating the email.

### Replying to a specific message

Each message has a reply button in its menu. Use this when a conversation has split into separate topics, or when you need to respond to an older message specifically. It sets the correct email headers so the thread stays tidy in the customer's inbox.

For normal, linear conversations, just reply to the latest message.
